# 代谢异常在线预测系统

这是一个 Streamlit 单页应用，现同时提供两类独立模型：

- 随访模型 A–D：估计未来 3 年发生代谢异常的概率。
- 横断面模型 E–F：估计当前检查时点存在代谢异常的概率。

两类结局的时间含义不同，页面会根据所选模型切换说明和结果文案；模型之间不做概率融合。

线上应用：[Metabolic Prediction App](https://j35jfd5cfgnkmlf2ulytj9.streamlit.app/)

## 新增横断面模型

- 模型 E：人口学/生活方式、BMI、腰臀比及体成分指标的 LASSO Logistic 模型。
- 模型 F：仅人口学/生活方式、BMI 和腰臀比的 LASSO Logistic 模型。

| 模型 | 固定20%内部测试集 ROC AUC | PR AUC | 判别阈值 | 灵敏度 | 特异度 |
|---|---:|---:|---:|---:|---:|
| E：人口学+体成分 | 0.799 | 0.537 | 0.253 | 69.9% | 74.8% |
| F：人口学基础 | 0.795 | 0.518 | 0.233 | 76.0% | 70.2% |

训练使用固定 20% 分层留出测试集。L1 正则强度只在训练集中通过分层 10 折交叉验证选择，并使用 1-SE 规则偏向简约模型；网页分类阈值来自训练集折外预测的最大 Youden J。评估完成后，固定正则强度和阈值，再用全体合格样本重拟合部署系数。

详细字段映射、数据清理、内部验证指标和非零系数见 `CROSS_SECTIONAL_MODEL_REPORT.md`。

> 数据质控提示：当前工作簿的“HDL异常”标签与修正后的 HDL-C 数值不一致。模型严格按用户指定的“代谢异常”列训练；临床使用或投稿前，应先确认 HDL 修正是否已同步重算标签，并在必要时重新训练。

## 横断面模型输入指标

模型 F 使用前7项；模型 E 使用表中全部指标。所有体成分指标应来自同一次检测。

| 指标 | 计算或获取方法 | 网页填写格式 |
|---|---|---|
| 性别 | 男性=1，女性=0 | 页面选择 |
| 年龄 | 检查日期减出生日期所得周岁 | 岁 |
| 运动频率 | 按平均每周次数分为 `<1`、`1–2`、`3–5`、`>5` 次 | 页面选择 |
| 吸烟史 | 从未=0；当前或既往吸烟/已戒烟=1 | 页面选择 |
| 饮酒史 | 否认=0；任何有饮酒记录（包括应酬性饮酒）=1 | 页面选择 |
| BMI | 体重(kg) ÷ 身高(m)²；使用临床“体重指数”，不要填写InBody“身体质量指数” | 例如22.86 |
| WHR | 腰围 ÷ 臀围，两者单位必须一致；按原表保留2位小数；使用临床“腰臀比”，不要填写“腰臀比INBODY” | 例如0.89 |
| 身体总水分 | 同一次体成分报告的 TBW | 报告数值，通常为L |
| 体脂肪量 | 同一次体成分报告 | kg |
| 体脂百分比 | 优先读取同次报告值；无报告值时可用体脂肪量 ÷ 体重 ×100%近似计算 | 28.3%填写28.3 |
| 上肢肌肉比率 | (右上肢肌肉量+左上肢肌肉量) ÷ 全身肌肉量（非骨骼肌量） | 0–1小数 |
| 躯干肌肉比率 | 躯干肌肉量 ÷ 全身肌肉量（非骨骼肌量） | 0–1小数 |
| 下肢肌肉比率 | (右下肢肌肉量+左下肢肌肉量) ÷ 全身肌肉量（非骨骼肌量） | 0–1小数 |
| ECW/TBW | 全身细胞外液总量 ÷ 身体总水分 | 0–1小数 |
| 上肢 ECW/TBW | (右上肢ECW+左上肢ECW) ÷ (右上肢TBW+左上肢TBW) | 0–1小数 |
| 上肢脂肪比率 | (右上肢脂肪量+左上肢脂肪量) ÷ 全身体脂肪量 | 0–1小数 |
| 躯干脂肪比率 | 躯干脂肪量 ÷ 全身体脂肪量 | 0–1小数 |
| 下肢脂肪比率 | (右下肢脂肪量+左下肢脂肪量) ÷ 全身体脂肪量 | 0–1小数 |
| TBW/FFM | 身体总水分 ÷ 去脂体重 | 报告73.4%时填写0.734 |

腰围、臀围和问卷项应沿用原研究的体检/问卷口径。体成分指标优先读取同一设备、同次检测导出的同名值；必须手算比例时，使用未四舍五入的原始分量。

## 本地运行

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## 重新训练横断面模型

训练脚本只读源 Excel，不会修改原始工作簿：

```bash
python train_cross_sectional_models.py "/path/to/横断面数据.xlsx"
```

脚本会在项目目录生成两份模型文件，以及 JSON/Markdown 格式的审计报告。

## 测试

```bash
python -m unittest discover -s tests
```

## 研究使用声明

横断面模型目前仅完成单一数据集内部验证，输出用于研究性筛查，不能替代临床诊断。正式临床应用前仍需独立外部验证、校准检查和临床效用评估。
