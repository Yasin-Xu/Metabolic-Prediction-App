# 代谢异常风险在线预测系统

- 上一版应用（保留不动）：<https://j35jfd5cfgnkmlf2ulytj9.streamlit.app/>
- A/B/C 新版目标地址：<https://metabolic-prediction-abc.streamlit.app/>

当前页面提供三个彼此独立的模型：

- **模型A（体成分+实验室）**：BMI、收缩压、体成分比例、糖化血红蛋白、总胆固醇、甘油三酯及系统计算的 TyG 指数。
- **模型B（精简体成分）**：性别、年龄、饮酒史、BMI、腰臀比和三个体成分指标。
- **模型C（人口学基础）**：年龄、饮酒史、BMI 和腰臀比。

新版页面不再加载此前的模型 E/F。三个模型分别输出代谢异常估计概率，并使用各自预先锁定的判别阈值；结果仅供研究性风险评估参考，不能替代临床诊断。

## 模型A输入与 TyG 计算

模型A固定使用以下工程特征：

1. 体重指数（kg/m²）
2. 收缩压（mmHg）
3. 下肢肌肉比率
4. 细胞外液总量/身体总水分（ECW/TBW）
5. 上肢肌肉比率
6. 下肢脂肪比率
7. 糖化血红蛋白（%）
8. 总胆固醇（mmol/L）
9. 甘油三酯（mmol/L）
10. TyG 指数

用户不需要手工填写 TyG。页面额外采集空腹血糖（mmol/L），并按下式自动计算：

```text
TyG = ln[(甘油三酯 mmol/L × 88.5) × (空腹血糖 mmol/L × 18) / 2]
```

体成分比例按 0–1 小数填写。下肢脂肪比率使用模型字段名 `下肢脂肪百分比`，实际含义为下肢脂肪量占全身体脂肪量的比例。

## 模型B与模型C输入

模型B按下列顺序使用八项特征：

1. 性别
2. 年龄（14–100岁）
3. 饮酒史
4. 体重指数（10–70 kg/m²）
5. 腰臀比（0.5–1.5）
6. 上肢脂肪比率（0–0.4）
7. 下肢脂肪比率（0.05–0.65）
8. 身体总水分/去脂体重（0.60–0.85）

模型C按下列顺序使用四项特征：年龄、饮酒史、体重指数和腰臀比；年龄、体重指数及腰臀比的输入范围与模型B相同。模型B和模型C均不需要吸烟史或运动频率。

性别与饮酒史在页面中直接选择。BMI = 体重(kg) ÷ 身高(m)²；腰臀比 = 腰围 ÷ 臀围。上、下肢脂肪比率均填写0–1小数。身体总水分/去脂体重也按0–1小数填写，例如73.4%填写0.734；页面会按模型训练口径自动换算。

## 模型文件

- `lab_model_a.pkl`
- `model_b.pkl`
- `model_c.pkl`

每个新版模型文件均保存预测管道、固定判别阈值和训练元数据。旧模型文件可继续保留作为内部记录，但不会被新版页面注册或加载。

## 重新训练模型

模型A：

```bash
python train_lab_model_a.py "/path/to/data.xlsx" \
  --raw-source "/path/to/SS-导出初始数据集20240804.xlsx" \
  --output-dir .
```

`--raw-source` 仅用于按体检号恢复原始缺失掩码；脚本不会修改任一源工作簿，也不会用旧数据覆盖当前观测值。若该文件与主数据位于同一目录且文件名未变，可省略此参数。开发记录见 `LAB_MODEL_A_REPORT.md`，机器可读元数据见 `lab_model_a_report.json`。

模型B与模型C：

```bash
python train_models_b_c.py "/path/to/data.xlsx" --output-dir .
```

该命令生成 `model_b.pkl`、`model_c.pkl`、`MODELS_B_C_REPORT.md` 和 `models_b_c_report.json`。训练脚本只读取源工作簿，不会修改源数据。
